# HR Analytics Dashboard

## Project Overview
This project focuses on analyzing employee data using Power BI to
understand workforce trends, employee risk, promotions, and demographics.

## Tools & Technologies
- Power BI
- Excel
- DAX
- Data Cleaning
- Data Visualization

## Key Analysis
- Employee demographics
- Gender analysis
- Promotion analysis
- Employee risk analysis
- Department-wise analysis
- Workforce insights

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- Data Modeling
- DAX
- Data Visualization
- Dashboard Development

## Project Outcome
Created an interactive HR Analytics Dashboard to help understand
employee trends and identify important HR metrics.
